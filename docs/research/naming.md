## 2. Eight alternatives from stage-management vernacular

Real call terms are favoured over tech-sounding coinages. The checks below are quick, not legal clearance.

1. **Hold the House**
   - Rationale: this is the stage manager's call to delay opening the doors when the stage isn't ready. It is exactly the decision the product helps avoid or manage.
   - Check: no app or company found (web search). GitHub has 0 repos for `holdthehouse` and 1 unrelated repo for `hold-the-house`. holdthehouse.com is registered (the page title reads "thelectioninsider.com", so it looks unrelated or parked). .app and .dev returned RDAP 404.
2. **Doors Call**
   - Rationale: names the deadline the whole graph runs toward, the doors-open call.
   - Check: no product found. Results were Doors Open Day apps, DoorList (college events) and The Doors band: https://webcatalog.io/apps/doorlist . GitHub has 0 repos for `doorscall`. .com, .app and .dev all returned RDAP 404.
   - Downside: weak SEO because of the band and "call centre" readings.
3. **Half Hour Call**
   - Rationale: the "half" is the universal pre-show countdown, a sense of time running out before the deadline.
   - Check: no product found. GitHub has 0 repos for `halfhourcall`; there are 28 for `halfhour`, for example `halfhourhq/halfhour`, an unrelated VPN server. halfhourcall .com, .app and .dev returned RDAP 404.
4. **Prompt Corner**
   - Rationale: the stage manager's station where the show is called (https://en.wikipedia.org/wiki/Prompt_corner). "Prompt" also hints at the agent.
   - Check: no product found. GitHub has 2 tiny repos, one of them about AI image prompts. promptcorner.com is registered (behind a Cloudflare challenge). .app and .dev returned RDAP 404.
   - Downside: "prompt" can read as generic AI, so it is a partial miss on the brief.
5. **Standby Go**
   - Rationale: the canonical "Standby... Go" calling sequence matches the product's propose-then-commit loop.
   - Check: StandByGo.com is for sale (HugeDomains page). standbygo.app is registered and standbygo.dev returned RDAP 404. GitHub has the `standbyGO` org and `SetMonkey13/StandbyGoCueLights` (theatre cue lights). There is also an adjacent Dutch emergency-staff app called "StandBy": https://apkcombo.com/standby/com.askcs.standby/
6. **Beginners Call**
   - Rationale: the UK call "Beginners to the stage" opens the show, and it is the moment everything must be in place.
   - Check: no product found. beginnerscall.com is registered (content not observed). "Beginners" reads as a tutorial in search results.
7. **Show Call**
   - Rationale: calling the show is the SM's live job, and the product is a rehearsal space for that.
   - Check: the "Showcaller" role is a feature name in Shoflo/Cvent and Lasso (https://www.lasso.io/articles/show-caller-tracking/). GitHub has `trevormarrr/showcall` (Resolume control) and `ShalyX/showcall` (event claims).
   - Downside: crowded in the events-tech space.
8. **Knock-On**
   - Rationale: the British crew idiom for a cascading consequence, which is the core concept stated plainly.
   - Check: no scheduling product found. GitHub has 131 `knock-on` repos, and Knock (a notification SaaS) is nearby: https://isdown.app/status/knock/incidents/612148-workflow-run-event-log-delays
   - Downside: this is crew slang, not strictly a stage call.

- **Spikemark:** Creative Conners' stage-automation software: https://shop.wengercorp.com/performance/spikemark-6.html
- **Cue to Cue:** two iOS theatre apps use the name: https://apps.apple.com/app/id1291690309
- **Gaffer:** `gchq/Gaffer` is a graph database (about 1.8k stars) and `GafferHQ/gaffer` has about 1.1k stars.
- **Cuelight:** `OlivierLmr/cuelight` is a discrete-event simulator, and `SALhik/CueLight` is a theatre cue light.
- **Understudy:** Understudy Labs (YC S26) and `understudy-ai/understudy` (463 stars): https://www.ycombinator.com/companies/understudy-labs

- **Flightcase, Ghostlight and Load-In:** many existing repos or products, and Load-In is generic.
